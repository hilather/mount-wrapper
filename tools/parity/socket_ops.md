- Newline-delimited JSON request/response
- Request: `{"v":1,"op":"…",…}` (missing `v` treated as 1)
- Response OK: `{"ok":true,…}` / error: `{"ok":false,"error":"…","code":"…"}`
- Auth: peercred root **or** group `mount-wrapper`; escape hatch `MOUNT_WRAPPER_CONTROL_ALLOW_UNAUTH`
- Socket path default: `/run/mount-wrapper/control.sock` (macOS under Caches)

## D6 cutover note

Operators must **not** point a tarmount-wsl CLI at a mount-wrapper socket (or vice versa).
Op names are intentionally familiar, but auth group, paths, error codes, and payload
shapes follow mount-wrapper only. See [docs/migration.md](../../docs/migration.md).
